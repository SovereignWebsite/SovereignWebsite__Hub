Ask Claude

For whoever keeps the hub: copy one of these into Claude, with write access to the repository.

Add a site

Read https://hub.sovereignweb.site/llms.txt and follow the instructions for the owner. Add the public site at [address] to site/sites.json in the hub-site format, take its screenshots with tools/take-shots.js, rebuild with tools/build-showroom.py, run the checks and push to dev.

Refresh the screenshots

Read https://hub.sovereignweb.site/llms.txt as the owner. Run tools/refresh.sh, tell me which sites did not answer, and push the new screenshots to dev if the checks pass.

Take a design round

Read https://hub.sovereignweb.site/llms.txt as the owner. Read the latest hub review in Site__Agents__Design docs/reviews/hub, fix its items one commit each, and tell me each release tag.

What changed this week

Read the commits of https://github.com/SovereignWebsite/SovereignWebsite__Hub on dev for the last seven days and summarise what changed on hub.sovereignweb.site, with a link for each point.

Check it is still safe

Read https://hub.sovereignweb.site/llms.txt as the owner. Check that no private or vault-only site is named anywhere in site/, that the site sets no cookies and makes no request to another host, and report what you find.

How this site was made

Everything that made this site is public, so you can check it.

The request

The hub is one of the SovereignWebsite organisation's own sites, not a request: its repository was seeded from the organisation's SovereignWebsite__IaC (see the first commits in its history). The sites it lists each began as a request in SovereignWebsite__IaC/requests.

The agents

The agents that work on this site are listed in data/agents.json, each with its name and its role. Each signs its commits with a key published at agents.sovereignweb.site.
