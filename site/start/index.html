If you keep this site

The rest of this page is for whoever keeps the hub. The site is static files in one GitHub repository, SovereignWebsite/SovereignWebsite__Hub. It is served at https://hub.sovereignweb.site from the site/ folder on the dev branch.

1. Connect GitHub

  1. Make a GitHub account at github.com/signup, if you do not have one.
  2. Send your GitHub login to the person who made this site. You get two invitations: one to the repository, with write (push) access, and one to join the SovereignWebsite organisation as a member. Membership gives you no access to anything else; it lets your own Claude work with your repository.
  3. Accept the repository invitation: signed in to GitHub, open the repository and press View invitation on the banner, or use the link in the email.
  4. Accept the organisation invitation at github.com/orgs/SovereignWebsite/invitation ("Join SovereignWebsite"). Use this address: the link in the email may not offer the button.
  5. If you use Claude, open its GitHub settings and press Check again next to SovereignWebsite. Until you are a member it shows "Needs reconnecting".

2. Make your first change

  1. Open the site folder on dev and pick the page to change (the home page is site/index.html).
  2. Press the pencil, edit, then Commit changes to the dev branch.
  3. The Pages workflow publishes it, and the site updates in a minute or two. The main branch is locked; everything goes through dev.

Or let your own AI agent make the change: see Use with your AI.

3. Ask for one more pass

Open an issue at https://github.com/SovereignWebsite/SovereignWebsite__Hub/issues/new saying what you would like changed, or ask the person who made the site. The site's agents work from the repository, so the issue is the record.

4. It is yours

The files, the history and the address are in a repository you control. You can move it anywhere, at any time: it is plain HTML with no server code, no cookies and no tracking.
